# OpenRare 🎗️

> 弥合信息鸿沟，让每一份罕见病研发进展触手可及。

**OpenRare** 是一个开源、非营利、面向公众与罕见病患者家属的**全球罕见病研发进展（Pipeline）追踪看板**。

全世界已报道的 7,000 多种罕见病中，超过 90% 缺乏有效治疗手段。对于许多家庭而言，最大的绝望往往来自于“信息不对称”。OpenRare 旨在通过社区开源协作的方式，梳理全球权威数据库与临床试验信息，用**通俗易懂的语言**展示罕见病的治疗进展与临床招募动态。

---

## 🌟 核心特色

* **去学术化与通俗化**：将复杂的基因编码与医学术语转化为普通人易懂的症状与机制说明。
* **专注于研发进展（Pipeline）**：实时追踪全球 ClinicalTrials 等平台的临床试验阶段（Phase I/II/III）与招募状态。
* **完全开源与零广告**：基于 GitHub Pages 构建，轻量高效，永不掺杂任何商业广告与利益相关推广。
* **数据结构化**：所有疾病条目均以 JSON/Markdown 形式存储，方便开发者与志愿者共同维护。

---

## ⚠️ 重要免责声明（Medical Disclaimer）

1. **非医疗建议**：OpenRare 仅作为一个开源信息的整理与展示平台，**不提供任何形式的诊断、治疗建议或用药推荐**。
2. **寻求专业帮助**：页面所列的所有临床试验与研发进展仅供科普参考。患者如需调整治疗方案，请务必咨询具有资质的专业临床医生。
3. **数据时效性**：临床试验数据与研发状态可能随时发生变化，请以官方临床试验注册库（如 ClinicalTrials.gov）及药品监督管理部门公布的最新信息为准。
